# VYBEX VPN — Android starter project

This is a native Android Studio starter project for the VYBEX VPN client UI.

## Build a debug APK

1. Open this folder in Android Studio (Jellyfish or newer).
2. Allow Gradle sync and install Android SDK Platform 35 if prompted.
3. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Android Studio writes the APK to `app/build/outputs/apk/debug/app-debug.apk`.

Alternatively, push the project to a GitHub repository and run the **Build Android APK** workflow. It uploads the debug APK as a workflow artifact.

## Important: VPN functionality is not implemented yet

The current app is an installable native UI starter, not a functioning VPN.
